نور الذكر V81 — Owner Studio

ما يمكن إدارته من لوحة المالك بدون تعديل كود:
- تشغيل/إيقاف أقسام الموقع.
- إظهار/إخفاء الأقسام من القائمة.
- تغيير أسماء الأقسام وترتيبها.
- تعديل النصوص الرئيسية.
- إضافة بطاقات ومحتوى جديد في مناطق جاهزة وحذفه.
- تشغيل/إيقاف المساعد الذكي.
- اسم المساعد، اسم Edge Function، النموذج، Temperature، حدود الإدخال والاستخدام.
- System Prompt ورسالة الأمان والأسئلة السريعة.
- الألوان، الانحناءات، الواجهة المضغوطة.
- وضع الصيانة ورسالة الصيانة.
- المستخدمون، الأذكار، الإعلانات، المحادثات، الأكاديمية والإعدادات السابقة.
- سجل تغييرات الإدارة موجود في security_audit.

ما لا يتم وضعه داخل لوحة الويب لأسباب أمنية:
- API Secret لمزود الذكاء الاصطناعي.
- Service Role Key.
- تشغيل كود JavaScript حر من قاعدة البيانات.
هذه الأشياء تبقى في Supabase Secrets/الكود؛ السماح بها من المتصفح يجعل اختراق حساب المالك اختراقًا كاملاً.

التثبيت في مشروع Supabase الجديد:
1) شغّل SUPABASE_V81_01_SCHEMA.sql.
2) أنشئ حساب المالك في Authentication.
3) شغّل SUPABASE_V81_02_MAKE_OWNER.sql.
4) اضبط Site URL وRedirect URLs.
5) ضع Project URL + Publishable Key في assets/js/config.js.
6) ارفع الملفات إلى GitHub Pages.
