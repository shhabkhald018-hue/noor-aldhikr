نور الذكر V81.4 — نسخة رفع نظيفة إلى GitHub

هذه الحزمة لا تحتوي على مجلد .git ولا أي index.lock.
لذلك لا ترفع المجلد القديم التالف داخل GitHub Desktop.

الطريقة الأكثر أمانًا:
1) فك الضغط في مجلد جديد.
2) افتح مستودع noor-aldhikr على github.com.
3) Add file > Upload files.
4) اسحب محتويات المجلد المفكوك كلها إلى صفحة الرفع.
5) Commit changes مباشرة على main.

بديل GitHub Desktop:
1) File > Clone repository.
2) اعمل Clone جديد للمستودع إلى مجلد جديد.
3) انسخ محتويات هذه الحزمة داخل المجلد الجديد فقط.
4) Commit ثم Push.

مهم:
- لا تنسخ أي مجلد .git من مجلد قديم.
- لا تضف Secret key أو service_role إلى الملفات.
- Project URL وPublishable key فقط موجودان في config.js.
