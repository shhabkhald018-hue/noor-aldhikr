1) ما هذا الإصدار؟
-------------------
هذا إصدار إنتاج آمن يركز على دقة المحتوى الشرعي ومنع المساعد من اختراع إجابات.
المساعد مجاني 100% ولا يستخدم OpenAI API أو Gemini API أو Claude API أو أي API مدفوع.
الإجابة العامة تأتي فقط من عنصر منشور، نشط، موثق بمصدر، ومرّ ببوابة المراجعة.

2) أهم ما تم تطويره وإصلاحه
---------------------------

- منع أي مسودة أو محتوى غير منشور أو بلا مصدر من الوصول إلى المستخدم.
- تثبيت رسالة الرفض الآمنة عند عدم وجود دليل كافٍ.
- إضافة تطبيع عربي ومطابقة مرنة وترتيب النتائج واقتراح الأسئلة القريبة.
- إيقاف محركات التوليد القديمة وإزالتها من تحميل الصفحات والكاش، مع إبقاء ملفاتها التاريخية دون حذف متعجل.
- توحيد إدارة قاعدة المعرفة داخل knowledge_base بدل ازدواج التحرير مع ai_knowledge.
- إضافة مسار مراجعة ونشر حقيقي لقاعدة المعرفة والدروس والأسئلة من لوحة المالك.
- أي إضافة جديدة تبدأ كمسودة غير نشطة، وأي تعديل في محتوى منشور يلغي اعتماده حتى يراجعه المالك مرة أخرى.
- تشديد RLS: المستخدم العام يقرأ المحتوى الموثق المنشور فقط، ولا يستطيع الكتابة أو جعل نفسه Owner.
- إبقاء ai_knowledge محفوظًا للتتبع التاريخي مع منع قراءته العامة.
- إصلاح لوحة المالك، مراقبة المساعد، ورسائل الحالة لتستخدم قاعدة المعرفة الموثقة.
- تحديث Service Worker والكاش إلى noor-aldhikr-v92-1-trusted-content.
- منع تخزين طلبات Supabase وواجهات API والصفحات الإدارية الحساسة في الكاش.
- تحديث جميع المسارات وإصدارات CSS/JS للعمل داخل /noor-aldhikr/ على GitHub Pages.
- فحص RTL، العرض على الهاتف، المسارات المحلية، الأصول، المعرفات المكررة، وبناء JavaScript.

4) ملف قاعدة البيانات
---------------------
الملف: SUPABASE_V92_1_TRUSTED_CONTENT.sql

تم تطبيق التحديث بالفعل على مشروع Supabase المرتبط بهذه النسخة أثناء التجهيز.
لا تُشغّل الملف مرة ثانية على المشروع نفسه إلا عند الحاجة أو بعد مراجعة حالة المشروع.

لتطبيقه على نسخة أخرى من قاعدة البيانات:
1. أنشئ نسخة احتياطية احترازية من المشروع.
2. افتح Supabase Dashboard ثم SQL Editor.
3. افتح SUPABASE_V92_1_TRUSTED_CONTENT.sql وانسخ محتواه كاملًا.
4. شغّل الملف مرة واحدة.
5. افتح لوحة المالك وشغّل التشخيص.

الملف غير مدمر ومصمم ليكون Idempotent قدر الإمكان؛ يضيف أعمدة وسياسات وفهارس ومحفزات مراجعة ولا يمسح المستخدمين أو المحتوى الحالي.

5) تشغيل الموقع محليًا
----------------------
لا تفتح index.html مباشرة باستخدام file:// لأن المصحف والكاش وطلبات الشبكة تحتاج خادمًا محليًا.

  npx http-server . -p 4173 -c-1

ثم افتح:
  http://127.0.0.1:4173/index.html

ولتشغيل الاختبارات:
